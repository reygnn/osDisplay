## A. From digitalClock's review

1. **Only the first seat was kept.** registry_global bound the first wl_seat and
   kept no other; when it went, osDisplay had no keyboard and pointer while another
   seat stayed. util.c now keeps the announced seats, up to eight, and
   registry_remove binds the oldest one left, as in digitalClock.
2. **Any scale was taken.** W, H and the cursor size times the factor overflow int
   from about 2^23. buffer_scale caps it at 16, as pulseControl and digitalClock.
3. **`-v` and `-h` exited 0 when stdout failed.** Fully buffered, the write fails
   only at exit. Now flushed and checked; `stdout: <error>` and exit 1. Tested with
   `/dev/full` and a closed stdout.

## B. osDisplay's own review

4. **"the old theme is gone" proved nothing.** It counted every wl_buffer destroy,
   and the window's buffers go at a scale change too, so it passed without
   `wl_cursor_theme_destroy`. Now it waits for the buffer last attached to the
   cursor surface, as digitalClock and pulseControl. Checked by taking the destroy
   out.
5. **A buffer wider than Cairo draws.** Past 32767 pixels Cairo draws nothing, and
   at scale 16 with about 3200 cores the shm pool passed INT32_MAX, which
   `wl_shm_create_pool` takes, so the compositor ended the connection. draw_scale
   now draws at the largest scale that fits; the compositor enlarges it. Tested in
   `make check` and with 900 cores at scale 4, which go at buffer scale 3. The
   screenshot alone does not tell: mwc keeps showing the last buffer it could take,
   so with the old code the window was blurred, not black.
6. **A failing poll was "lost the connection: Success".** No libwayland error is set
   then. Now `poll: <error>`. Tested with an LD_PRELOAD poll that fails
   (tests/failpoll.c).
7. **deskControl from two desktops on.** README and CAVEATS still said so;
   deskControl has two rows with one desktop too since its commit 558bf05.
8. **"One C file" in the README,** wrong since util.c. The header comment of osd.c
   had a line past 100 columns from 6be2d1b; wrapped again.
